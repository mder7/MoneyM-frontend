# MoneyM — фронтенд «Сумма дивидендов»

SPA на React + TypeScript (Vite), компоненты React-Bootstrap, маршрутизация react-router-dom.
Архитектура FSD: `app / pages / widgets / features / entities / shared`.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

Веб-сервис NestJS должен работать на `http://localhost:3000`.
Vite проксирует запросы `/api/...` на веб-сервис (`vite.config.ts`).
Если веб-сервис недоступен, данные берутся из mock-коллекции (`entities/shareholder/model/mock.ts`).

## Страницы

### «Плитка» — `/tiles`
Список опубликованных акционеров МКПАО «Яндекс» в виде плитки по 2 карточки в ряд.

| Элемент | Описание |
|---|---|
| Заголовок «Акционеры» | название страницы |
| Слайдер «от N %» | минимальная доля владения (0–30 %) |
| Кнопка «Найти» | применяет фильтр: `GET /api/shareholders?minShare=N`. Без нажатия запрос не выполняется |
| Карточка | фото (или изображение по умолчанию), ФИО/название, доля владения, число лайков. Нажатие — переход на `/feed/{id}` |

### «Лента» — `/feed`, `/feed/{id}`
Одна карточка акционера на весь экран.

| Элемент | Описание |
|---|---|
| Фон | видео акционера или видео по умолчанию, постер — фото или изображение по умолчанию |
| Справа | доля владения, доля в привилегиях, число лайков |
| ФИО/название | внизу экрана |
| Кнопка «Больше» / «Скрыть» | показывает/скрывает краткое описание |
| Кнопка «Далее» | `GET /api/shareholders/feed/{id}?next=true`, адрес меняется на `/feed/{новый id}` |

Первая карточка: `GET /api/shareholders/feed`, карточка по адресу: `GET /api/shareholders/feed/{id}`.

## Нижняя навигация
4 пункта: **Лента**, Добавить, **Плитка**, Вход (справа).
Активны только «Лента» и «Плитка», «Добавить» и «Вход» — неактивны (будут в следующих лабораторных).

## Изображение и видео по умолчанию
